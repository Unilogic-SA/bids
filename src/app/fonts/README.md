# OpenBids font assets

Same font families as the established product: Inter (100–900), Figtree (300–900)
and Geist Mono (100–900). Downloaded on 21 October 2026 from Google Fonts'
official source distribution and compressed to WOFF2, retaining variable weights.
Subsets cover Latin/Latin Extended including African Latin letters, punctuation,
currencies and common mathematical symbols. Other scripts use browser fallback.

- https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/figtree/Figtree%5Bwght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/geistmono/GeistMono%5Bwght%5D.ttf

The adjacent OFL files preserve the upstream license notices. These are font
assets; no Python or font-conversion dependency is required to build the app.
